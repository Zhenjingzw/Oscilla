# Oscilla

A minimalist pendulum metronome.

## Controls

| Action | Desktop | Mobile |
|--------|---------|--------|
| Start / Stop | Click BPM number or Space | Tap BPM number |
| Adjust BPM | Scroll wheel or drag number | Drag number |
| Time signature | Scroll or drag each number | Tap or drag each number |
| Beat accent | Click dot to cycle | Tap dot to cycle |
| Theme | Click O in title | Tap O in title |
| Swing direction | Click right half of title | Tap right half of title |
